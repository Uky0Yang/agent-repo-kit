# Roadmap

## Near Term

- Implemented in v0.2.0: `typescript-cli` and `awesome-list` templates
- Add `--init-git` option
- Add `--run-checks` option after generation
- Add template snapshot tests

## Mid Term

- Add `--github` option to create and push through GitHub CLI
- Add optional integration with `oss-launch-check`
- Add optional integration with `repo-context-card`
- Add PyPI release

## Long Term

- Maintain a gallery of generated example repositories
- Add plugin-based external templates
- Add template profiles for Codex, Claude Code, Cursor, Copilot, and Gemini CLI

## Non-Goals

- No default network calls
- No hidden telemetry
- No claims that generated projects will automatically get stars
